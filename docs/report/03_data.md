# 3. Data and Exploratory Analysis

## 3.1 Source

We use the **MIT-Stanford-Toyota** fast-charging dataset (Severson et al., 2019), downloaded from MATR.io. It contains commercial **LFP/graphite** pouch cells cycled under varied fast-charge policies. Raw data: **140 JSON files** (`FastCharge_*_structure.json`), one per test record.

Each JSON file includes:
- **`summary`:** 16 per-cycle fields (capacity, energy, resistance, temperature, etc.)
- **`cycles_interpolated`:** high-resolution voltage/current/temperature curves (not exported to CSV due to size)

### End-of-life definition

- Initial capacity: first `cycle_index ≥ 1` discharge capacity  
- EOL: first subsequent cycle with `discharge_capacity < 0.8 × initial`  
- If threshold never reached: EOL = last cycle (censored)

### Cleaning (Week 2)

Raw data has **140 files** but **134 unique barcodes** (five barcodes tested twice; one partial test). We apply **longest-run-wins dedupe**: keep the file with the higher EOL for each duplicate barcode; drop five short reruns and one formation-only partial cell (`el150800737381`). Each retained row has a unique `file_id` (JSON filename) and `cell_id` (barcode). Full rule: `docs/week02/duplicate_barcode_policy.md`.

## 3.3 Exploratory analysis

### End-of-life distribution

Across **134** labeled cells in `cell_targets.csv`:

| Statistic | EOL (cycles) |
|-----------|----------------|
| Minimum | 159 |
| Median | 792 |
| Maximum | 2,237 |
| Mean | ~822 |

![EOL distribution](../../results/figures/eol_distribution.png)

The wide spread (159–2,237 cycles) matches the high variability reported by Severson et al. and motivates **cell-level** train/validation/test splits for modeling (no random row splits).

Figure below shows discharge capacity vs cycle for one cell (`el150800440551`), with the 80% threshold and computed EOL marked. Capacity stabilizes near ~1.05 Ah after cycle 1; fade accelerates later in life.
